JavaScript'te aritmetik işlemler, sayısal veriler üzerinde matematiksel hesaplamalar yapmak için kullanılır. JavaScript, temel aritmetik işlemleri gerçekleştirmek için çeşitli operatörler sunar. Bu operatörlerin nasıl kullanılacağını ve hangi işlemleri gerçekleştirdiğini aşağıda detaylı bir şekilde açıklayacağım.
Temel Aritmetik Operatörler


Toplama (+)

İki veya daha fazla sayıyı toplamak için kullanılır.

Ayrıca, iki string’i birleştirmek için de kullanılabilir.

let a = 5;
let b = 3;
let toplam = a + b; // 8

let metin1 = "Merhaba, ";
let metin2 = "dünya!";
let birlesim = metin1 + metin2; // "Merhaba, dünya!"


Çıkarma (-)

Bir sayıyı diğerinden çıkarmak için kullanılır.

let fark = a - b; // 2


Çarpma (*)

İki sayıyı çarpmak için kullanılır.

let carpim = a * b; // 15


Bölme (/)

Bir sayıyı diğerine bölmek için kullanılır. Sonuç ondalıklı olabilir.

let bolum = a / b; // 1.666...


Mod Alma (%)

Bir sayının diğerine bölümünden kalanını bulmak için kullanılır.

let kalan = a % b; // 2


Üs Alma (**) (ES6 ile gelmiştir)

Bir sayının üsse yükseltilmesi için kullanılır.

let us = a ** b; // 125 (5^3)



Aritmetik Atama Operatörleri

JavaScript, değişkenlere değer atarken aritmetik işlemleri kısayol şeklinde yapmanıza olanak tanır. İşte bazı örnekler:

Toplama ve Atama (+=)

a += b; // a = a + b;


Çıkarma ve Atama (-=)

a -= b; // a = a - b;


Çarpma ve Atama (*=)

a *= b; // a = a * b;


Bölme ve Atama (/=)

a /= b; // a = a / b;


Mod Alma ve Atama (%=)

a %= b; // a = a % b;


Üs Alma ve Atama (**=)

a **= b; // a = a ** b;
