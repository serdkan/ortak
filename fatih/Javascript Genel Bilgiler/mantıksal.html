JavaScript'te mantıksal operatörler, boolean (doğru ya da yanlış) değerler üzerinde işlemler yaparak yeni boolean değerler üretmek için kullanılır.
Mantıksal operatörler genellikleullu ifadelerde ve kontrol yapılarında kullanılır. İşte en yaygın mantıksal operatörler:
1. Mantıksal (&&)


İki ifadenin her ikisi de doğruysa true, aksi takdirde false döner.

Örnek:


javascript
let a = true;
let b = false;
let sonuc = a && b; // false

### 2. Mantıksal OR (`||`)
- İkiadenin en az birisi doğruysa `true`, her ikisi de yanlışsa `false` döner.
- Örnek:

```javascript
let a true;
let b = false;
let sonuc = a || b; // true

let a = true;
