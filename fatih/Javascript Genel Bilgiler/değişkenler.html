JavaScript'te değişkenler (variables), programda veri saklamak ve manipüle etmek için kullanılır. Değişkenler, belirli bir değeri veya referansı tutan isimlendirilmiş bellek alanlarıdır. JavaScript’te değişken tanımlamak için birkaç temel yöntem ve kurallar bulunmaktadır. Aşağıda bu konuyu detaylı bir şekilde açıklayacağım.
Değişken Tanımlama

JavaScript'te değişken tanımlamak için üç anahtar kelime kullanılır:

var

let

const


1. var


var, ES5 ve öncesi sürümlerde değişken tanımlamak için kullanılan klasik bir anahtar kelimedir.

var ile tanımlanan değişkenler, fonksiyon kapsamına (function scope) sahiptir. Yani, bir fonksiyon içinde tanımlandıysa, o fonksiyon dışında erişilemezler. Ayrıca, bir var değişkeni, tanımlandığı yerde yeniden tanımlanabilir.


var x = 10;
console.log(x); // 10

if (true) {
var x = 20; // aynı değişkeni tekrar tanımladık
console.log(x); // 20
}
console.log(x); // 20 (fonksiyon kapsamı nedeniyle dışarıda da aynı x'i gösterir)

2. let


let, ES6 (ECMAScript 2015) ile tanıtılan bir anahtar kelimedir.

let ile tanımlanan değişkenler blok kapsamına (block scope) sahiptir. Bu, değişkenin yalnızca tanımlandığı blok içinde erişilebilir olduğu anlamına gelir. Ayrıca, let ile tanımlanan değişkenler, birden fazla kez tanımlanamaz.


let y = 10;
console.log(y); // 10

if (true) {
let y = 20; // farklı bir y tanımlandı
console.log(y); // 20
}
console.log(y); // 10 (dışarıda tanımlanan y etkilenmedi)

3. const


const, sabit değişkenler için kullanılır ve yine ES6 ile tanıtılmıştır.

const ile tanımlanan değişkenler de blok kapsamına sahiptir. Ancak const ile tanımlanan bir değişkenin değeri bir kez atandıktan sonra değiştirilemez. Bu, sabit bir referans olduğu anlamına gelir.

const z = 30;
console.log(z); // 30

// z = 40; // Bu kod hata verir: "Assignment to constant variable."

if (true) {
const z = 40; // farklı bir z tanımlandı
console.log(z); // 40
}
console.log(z); // 30 (dışarıda tanımlanan z etkilenmedi)

Değişken İsimlendirme Kuralları

Değişken isimleri aşağıdaki kurallara uymalıdır:

İlk karakter harf, $, veya _ ile başlamalıdır. Sayı ile başlayamaz.

Büyük/küçük harf duyarlılığı vardır: myVariable ve myvariable farklı değişkenlerdir.

Boşluk, özel karakter veya anahtar kelimeler kullanılamaz.


Veri Türleri

JavaScript’te değişkenler, farklı veri türlerini tutabilir:

Primitive Veri Türleri: string, number, boolean, null, undefined, symbol (ES6 ile eklenmiştir).

Referans Veri Türleri: object, array, function.


Örnek Kullanım
let name = "Alice"; // string
const age = 25; // number
var isStudent = true; // boolean

const person = {
name: "Alice",
age: 25,
};

let scores = [100, 90, 85]; // array

Sonuç

JavaScript'te değişkenler, kodunuzda veri saklamak ve yönetmek için kritik bir rol oynar. Doğru değişken tanımlama anahtar kelimesi seçimi, kodunuzun kapsamını ve davranışını etkileyebilir. `let` ve `const` kullanımı, `var` kullanımına göre daha modern ve güvenli bir yaklaşımdır. Bu nedenle, güncel JavaScript kodlarında `let` ve `const` tercih edilmesi önerilir.
